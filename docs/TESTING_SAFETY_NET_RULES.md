# 안전망 규칙 (Safety Net Rules)

> 🗓️ 제정: 2026-09-14 · 정본(single source of truth)
> 📌 적용 대상: `medication-frontend/e2e/**`(Playwright) · `medication-frontend/__tests__/**`(Vitest+RTL)
> 🎯 목적: **서비스 개선의 토대**. 개선 전에 "지금 무엇이 참인가"를 실행 가능한 형태로 못 박아,
> 리팩터·기능 변경이 무엇을 깨뜨렸는지 즉시 드러나게 한다.

---

## 1. 정의와 합격 판정

**안전망** = 변경 전후로 **불변이어야 하는 계약**을 실행 가능한 테스트로 고정한 것.

판정 질문 (하나라도 '예'면 안전망이 아니다):

- [ ] 이 테스트가 **통과하는데도** 사용자가 깨진 화면을 볼 수 있는가?
- [ ] 테스트가 검증하는 전제(데이터·세션)가 **없어도 통과**하는가?
- [ ] 실패했을 때 **어디를 봐야 할지** 로그만으로 모르는가?

> 통과가 위험을 덮는 테스트는 부채다. "초록"이 아니라 **"초록의 의미"**를 관리한다.

## 2. 층 배분 — 어디에 쓸 것인가

| 관측 지점 | 층 | 도구 |
|---|---|---|
| 브라우저 주소 · 네트워크 · 여러 페이지 이동 · 실제 인증 | 흐름 | Playwright E2E |
| 렌더 결과 · 내부 상태 · **참조 안정성** · 호출 인자 | 컴포넌트/컨텍스트 | Vitest + RTL |
| 순수 함수 · 포맷터 · 파생 계산 | 유닛 | Vitest |
| **DB 에 실제로 남은 것** — 스키마 정합 · 삭제 결과 · 소유권 · cascade · 제약 | **BE DB 층** | **pytest + 진짜 Postgres** (`app/tests/db/`, `@pytest.mark.db`) |
| 서비스 로직 · 에러 변환 · 외부 경계 | BE 유닛 | pytest (+ mock) |

**원칙**: 관측이 까다로운 내부 동작(참조·재계산·리렌더)을 E2E 로 억지로 잡지 않는다.
E2E 로 관측 불가능하다는 사실 자체가 **"컴포넌트 층으로 내려라"**는 신호다.

> 실례: `main` 의 챌린지 재추첨은 E2E 로 관측 불가(프로바이더를 리렌더시키는 사용자 조작이
> 그 화면에 없다) → 뿌리인 `ChallengeContext` 의 **파생 배열 참조 유지**를 Vitest 로 잠갔다.

### 2-1. BE DB 층 규칙 (2026-09-15 신설, C12-b)

> **mock 은 "우리가 호출한 것"을 검증하고, DB 는 "실제로 남은 것"을 검증한다.**
> FK 제약 · 트리거 · cascade 는 **소유한 시스템이라도 대역으로 대신할 수 없다.**
> 실제로 이 층을 만들자마자 mock 이 5개월간 못 잡던 결함 2건이 나왔다
> (`docs/tech-debt/delete-semantics-mismatch.md`).

| # | 규칙 | 왜 |
|---|---|---|
| **R13** | **스키마는 `generate_schemas()` 가 아니라 마이그레이션으로 만든다** | 모델에서 바로 만들면 마이그레이션 체인이 영원히 미검증이다. prod 가 코드보다 24 마이그레이션 뒤처졌던 사고의 구조 |
| **R14** | **DB 가 없으면 skip 이 아니라 _실패_ 시킨다** | skip 은 "검증하지 않았다"를 초록으로 만든다. `test_vector_field.py` 자리표시자 3건이 그 상태로 **5개월간 초록**이었다 |
| **R15** | **느린 층은 마커로 분리하되, 실행 여부를 CI 가 보장한다** | `-m db` 를 별도 스텝으로. pytest 는 수집 0건이면 **exit 5** 라, 층이 통째로 안 돌면 빨개진다. 한 줄로 합치면 "0건 실행"이 조용히 초록 |
| **R16** | **ORM 객체 속성이 아니라 DB 행 값을 단언한다**(`.values(...)`) | ORM 디스크립터는 타입 추론·캐시가 끼어든다. 저장된 값을 보려면 읽어와야 한다 |
| **R17** | **허용목록에는 사유를 강제하고, 허용목록 자체를 검사한다** | 차이날 때마다 넣으면 정합 테스트가 **통과 기계**가 된다 |

**도구가 "괜찮다"고 한 것은 관측이 아니다.** `aerich migrate` 의 *"No changes detected"* 는
마이그레이션 파일 안 `MODELS_STATE` 스냅샷 비교일 뿐 **실 DB 를 보지 않는다.**
정합은 두 스키마를 실제로 만들어 **introspect 로 대조**해야 한다.

## 3. 단언 규칙 (필수)

| # | 규칙 | 금지 예 | 대신 |
|---|---|---|---|
| **R1** | **전제는 skip 이 아니라 단언** | `test.skip(count === 0)` | 시드가 보장 → `expect(count).toBeGreaterThan(0)` |
| **R2** | **대기 실패를 삼키지 말 것** | `await waitFor(...).catch(() => {})` | `await expect(locator).toBeVisible()` |
| **R3** | **존재가 아니라 "차이"를 단언** | "텍스트가 있다" | 매핑 결과가 **관측 가능한 차이**로 드러나게 (예: USER=원문 / ASSISTANT=Markdown 렌더) |
| **R4** | **mock 필드명을 실제 계약과 대조** | 추측한 `role` | BE 응답 DTO 확인 후 `sender_type` |
| **R5** | **시드는 스스로 전제를 단언** | 생성 호출만 하고 끝 | 생성 후 재조회해 **개수·상태 단언** |
| **R6** | **skipped 0 유지** | skip 개수가 실행마다 흔들림 | 흔들림 자체가 결함 신호 → 원인 규명 |
| **R7** | **실패는 결정적으로** | flaky 를 `retries` 로 덮음 | 원인(레이트 리밋·타이밍) 제거 |
| **R8** | **확률적 동작은 집합 단언** | "A 가 뜬다" | "A·B 중 **정확히 1건**이 뜬다" |
| **R9** | **실패 사유를 한국어로 동봉** | `expect(x).toBe(y)` | `expect(x, '왜 이래야 하는지').toBe(y)` |
| **R10** | **화면 전체 텍스트 검색 금지** | `page.getByText('두통')` | 검증 대상 영역 안에서만 — `page.getByTestId('...').getByText('두통')` |
| **R11** | **스텁 값은 고유 센티널로** | `symptoms: ['두통']` | `symptoms: ['E2E증상_QX7']` — 프리셋·라벨·안내문과 충돌 불가 |
| **R12** | **대기 지점은 settled 에서만 참인 값으로** | `findByText('0')` (로딩 중에도 0) | `waitFor(() => expect(getByTestId('loading')).toHaveTextContent('false'))` |

#### R10 — 왜
같은 문자열이 화면 다른 곳(프리셋 칩·라벨·안내문)에 있으면, 검증 대상이 렌더되지 않아도
통과한다. **실제로 2건 모두 이 경로로 헛된 초록이 됐다**(대장 D19 / 원장 V1).
검증 대상 영역에 testid 가 없으면 **소스에 testid 를 추가**한다 — 테스트가 볼 경계를
노출하는 것은 정당한 소스 변경이고, 동작 변경이 아니므로 커밋만 분리하면 된다.

#### R11 — 왜
스텁 값을 실제 도메인 단어(`'두통'`·`'복통'`)로 지으면 화면의 정적 텍스트와 겹칠 확률이
높다. `'E2E증상_QX7'` 처럼 **앱 어디에도 없는 문자열**이면 조회가 실제로 일어나 렌더된
경우에만 화면에 나타난다. 숫자·짧은 단어(`'0'`·`'true'`·`'empty'`)도 같은 이유로 금지.

#### R12 — 왜
`findByText('0')` 은 "0 이 나타날 때까지" 기다리는데, **로딩 중에도 목록 길이는 0** 이다.
2026-09-15 결핍 주입 실측: `api.get` 이 **영원히 응답하지 않아도** 컨텍스트 테스트 3건이
전부 통과했다. 대기 지점은 **조회가 끝난 뒤에만 참인 값**(`isLoading=false`·`isError=true`)
이어야 한다. `.first()` 는 다중 매칭 경보를 끄므로 **이유를 주석에 적은 경우에만** 허용한다.

### 선택자 우선순위
`getByRole` → `data-testid` → `getByText` → (최후) 클래스.
클래스 선택은 **"현재 DOM 계약"이라고 주석에 명시**한 경우에만 허용한다.

## 4. 얇게 vs 두껍게 — 도메인 휘발성에 따른 투자

| 구분 | 도메인 | 잠그는 범위 |
|---|---|---|
| **휘발성(얇게)** | 챌린지 · OCR 처방전 업로드 · 생활습관 가이드 | **구조적 계약만** — "활성 항목이 있으면 그중 하나를 렌더", "업로드 후 결과 화면으로 이동" |
| **안정(두껍게)** | 인증 · 라우팅 · 공용 컨텍스트 · **챗봇 흐름** | 상태 전이·에러 표면화·발신자 구분까지 |

> ⚠️ **"얇게" ≠ "느슨하게"**. 단언 문장 자체는 언제나 정확·구체적이어야 한다
> (몇 건인지, 어떤 URL 인지, 어떤 역할인지). 얇다는 건 **단언의 개수와 대상 범위**이지
> 정밀도가 아니다.
>
> 휘발성 도메인 스펙에는 **"의도적으로 단언하지 않는 것"**을 파일 주석에 적는다.
> 기능이 바뀔 때 무엇을 고쳐야 하는지가 그 줄에서 바로 보인다.

## 5. 외부 의존 (mock drift 방어)

1. **대역은 "남의 시스템" 경계까지만**. 우리 코드 경로는 가짜로 바꾸지 않는다.
   - 카카오 로그인 → **mock IdP + 진짜 콜백**(세션 발급·쿠키·리다이렉트는 실코드로 검증)
   - LLM 응답 → `page.route()` 인터셉트로 고정
2. **한계를 스펙 파일 주석에 명시**한다. (예: "모델 교체·응답 스키마 드리프트는 이 스펙이 못 잡는다")
3. mock 라우트·백도어는 **반드시 로컬 게이팅**(`ENV=local`)하고, 프로덕션 노출 여부를 확인한다.

## 6. 파일 작성 규약

모든 스펙/테스트 파일 상단에 다음 5줄 블록을 둔다(한국어, `─` 박스 주석).

```js
// ── [대상] 특성화 ([작업 단위]) ──────────────────────────────
// 흐름: [진입] -> [동작] -> [관측 지점]
// 잠그는 동작:
//   (1) ...  (2) ...
// ⚠️ 의도적으로 단언하지 않는 것: ...
// 전제: docker fastapi(:8000) 기동 + auth.setup 세션 + seed.setup 의 [데이터]
```

## 7. 실행 순서 (함정)

1. **소스 변경 → `npm run build` → E2E**.
   Playwright 기본 타깃이 `static`(빌드 산출물 `out/` 서빙)이라 빌드를 건너뛰면 **옛 코드를 검증**한다.
   빠른 반복은 `E2E_TARGET=dev`.
2. `docker compose ps` 로 **fastapi healthy** 확인. 미기동이면 인증 테스트가 전부 실패한다.
3. 전체 스위트는 레이트 리밋에 걸릴 수 있다 → 로컬 compose 만 한도가 완화돼 있다(기본값은 불변).

## 8. 커밋 전 체크리스트

- [ ] skipped **0** 인가
- [ ] 새 스펙이 **리팩터 전 코드에서** 의도한 색(Green 또는 의도된 Red)인가
- [ ] **이 스텁/시드를 비우면 빨개지는가** (결핍 주입 1분 — A형이 아니라 **B형** 헛된 초록을 잡는 유일한 수단)
- [ ] 대기 지점이 **로딩 중에도 참인 값**은 아닌가 (R12)
- [ ] 시드를 **두 번 연속 실행**해도 통과하는가(멱등)
- [ ] 모든 `expect` 에 실패 사유가 붙어 있는가
- [ ] 파일 상단 주석에 **잠그는 동작 / 단언하지 않는 것 / 전제**가 적혀 있는가
- [ ] `npm run lint` **0 error**

**BE DB 층을 건드렸다면 추가로**
- [ ] `pytest app -m db` 가 **0건이 아니라** 실제로 선택되는가
- [ ] 지키려는 것을 깨면(필터 한 줄 제거 · 분기 반전 · raw SQL 주석) **빨개지는가**
- [ ] 실제 동작이 주석·docstring 과 다르면, **테스트는 실제를 잠그고 불일치를 명시**했는가
      → 그리고 `docs-private/FOLLOWUP_QUEUE.md` 에 등재했는가 (**놓치면 그 주석은 영원히 거짓**)
